# Code-review pack

The corpus is generated by `mutate.py` from 12 small clean Python functions. Each seeded case applies
one textual mutation and derives its label and 1-based finding line from that mutation. Every mutated
case is paired with its original clean function under the same category, so calibration measures
both issue detection and false positives. Calibration and held-out use different source functions.
Calibration has one positive and one clean example per category. Held-out has the same, plus a second
positive SQL-injection example.

Generate or refresh the files with:

```bash
python3 packs/code-review/mutate.py
```

The generator writes 12 calibration and 14 held-out examples (26 total). They are synthetic and
support pipeline development, not evidence of
production security performance. Spot-check the mutations and labels before publishing evaluation
claims.
